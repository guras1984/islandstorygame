# 아일토피아 · ISLETOPIA

플레이: https://guras1984.github.io/islandstorygame/isletopia.html

카피바라 친구 카피와 무인도에서 시작하는 1인용 3D 웹 게임입니다. 계정·친구 방문·Roblox 이전은 추후 작업으로 남겨둡니다.

## 실행

`dist`를 정적 서버로 제공하세요. 예: `python3 -m http.server 8090 --directory dist`.

## 성장과 경제

- 중심 보금자리: 모닥불 → 동굴 → 누더기집 → 초가집 → 작은집 → 집 → 큰집 → 빌라. 총 8단계이며 각각 다른 모델로 표시합니다.
- 모닥불은 목재 3·석재 2로 시작합니다. 보금자리 단계에 따라 시설과 추가 업그레이드가 열립니다. 오른쪽 목표 카드는 실제 다음 행동과 보유량/필요량을 안내합니다.
- 추가 주민 주택은 중심 보금자리와 별개입니다. 빈방과 시설을 보고 방문자가 찾아오며 입주 허락 후 인구가 증가합니다. 주민에게 자원 수집을 맡길 수 있습니다.
- 카피는 처음부터 함께합니다. 클릭하거나 가까이에서 E로 대화하고 재료를 수량별로 사고팔 수 있습니다. 구매 가격은 판매 가격의 3배이고 음수·소수·과다 수량은 거절합니다.
- 건물은 재료로 건설합니다. 큰집(7단계)에서 항구가 열리고, 항구에서 탐험선을 금화 80으로 구매합니다. 빌라·항구 3단계·탐험선 2단계에서 대형선을 금화 250으로 구매합니다. 배 업그레이드도 금화로 지불합니다.

## 채집과 낚시

- 자원을 한 번 클릭하면 다가간 뒤 한 번 작업합니다. 나무·돌은 3초, 열매·버섯은 2초입니다. 완료 시 재료 1개만 지급하며 반복 클릭은 작업을 중복시키지 않습니다. 이동·다른 행동으로 중단하면 지급하지 않습니다.
- 도끼·곡괭이·손 뻗기·몸 숙이기 동작을 구분합니다. 건설·업그레이드는 약 2.4초 동안 빛과 탄성 효과를 표시합니다. 조작을 강제로 막지 않습니다.
- 처음부터 기본 낚시터가 제공됩니다. 낚시터에서만 낚시할 수 있습니다. 도착 후 앉아서 자동 장착 → 던지기 2초 → 기다리기 4~6초 → 입질 2.5초 → 자동 인양 2.2초 → 결과 순서입니다. 계속 잡기 또는 그만하기를 선택합니다. 취소·이동하면 도구와 찌를 정리합니다.
- 작은물고기·바닷물고기·해초·조개·재활용 조각·유목을 낚고, 2단계 낚시터부터 달빛물고기·상자를 낚습니다. 주변 물고기·먼바다 상어·떠다니는 쓰레기도 표시합니다.
- 해초·조개·재활용 조각은 보금자리와 창고·낚시터 업그레이드 및 선택 이벤트에 사용합니다. 카피가 기본 특수 재료도 팔기 때문에 희귀 어획 때문에 성장이 막히지 않습니다.
- 채집·생산 메뉴의 가방에서 어획물을 확인하고 물고기를 식량으로, 유목을 목재로 손질하거나 상자를 열 수 있습니다.

## 이웃과 생활

- 카피와 이야기하거나 물고기를 선물하면 하루별 친밀도가 오릅니다. 3·6·10점에 꾸미기 선물을 한 번씩 받습니다.
- 주민은 정원·바다·비·산책을 좋아하는 성격을 가지며 꽃을 구경하거나 벤치에 앉거나 낚시터·빗속을 찾아갑니다. 주민별 작은 부탁과 하루별 선물 반응도 있습니다.
- 자연 메뉴에서 벤치·들꽃·돌길·울타리·조명을 놓고, 놓인 장식을 클릭해 이동하거나 돌려받습니다. 선물 장식은 재료 없이 한 번씩 배치할 수 있습니다.
- 저녁 18~22시에는 주민과 동물이 모닥불 주변에 모입니다. 원할 때 참여할 수 있고 하루 한 번 작은 간식을 나눕니다.
- 발견 도감은 물고기·해변 물건·동물·카피를 처음 만난 날을 기록합니다. 5종마다 조명 선물을 받습니다.
- 매 게임 날짜에 해변 편지병·조개·유목이 나타납니다. 편지와 관련된 화단 부탁, 바다 청소와 물고기 저녁 이벤트는 선택 사항이며 보상은 한 번만 지급합니다. 기존 게시판 이벤트도 유지합니다.
- 낮밤·비·우산·무지개·버섯·합성 배경음악을 유지합니다. 하루는 실제 20분이며 계정의 실제 날짜와 무관한 게임 시간입니다.

## 화면과 조작

- 모바일은 항상 가로 구성입니다. 세로 접속 시 전체 게임을 90도 회전해 표시하며 터치 좌표도 변환합니다. 조이스틱은 왼쪽 아래 드래그 중에만 반투명하게 나타나고 손을 떼면 숨깁니다.
- 드래그로 상하좌우 시점을 조절합니다. 수직 각도는 땅 밑으로 들어가지 않도록 제한하며 휠·두 손가락 줌을 유지합니다. 한글 입력 상태에서도 WASD·방향키로 이동합니다.
- 자원 5종은 상단에 항상 고정합니다. 6개 관리 메뉴는 하단 가로 배치, 오른쪽 목표 카드는 접고 펼칠 수 있습니다. 접은 상태는 별도 브라우저 설정으로 저장합니다.
- 관리 목록은 하단 메뉴 위의 작은 반투명 카드이며 설명과 재료는 자세히 보기로 확인합니다. 건설은 초록색 위치를 클릭·터치하면 즉시 확정하고 재료를 지불합니다. 빨간 위치·드래그·핀치는 건설로 처리하지 않습니다. 회전과 취소는 별도 버튼으로 유지합니다.
- 완료 알림은 중앙의 반투명 카드, 재료 획득은 캐릭터 옆, 대화는 하단 메뉴 위에 표시합니다. 스킵해도 필요한 선택지는 남습니다.

## 저장·검증·배포

기존 키 `island-nation-v1`로 브라우저에 자동 저장합니다. 새 시스템을 저장한 뒤에도 건물·배치·주민·작업·날씨·이벤트·외형·어획물·도감·장식·친밀도가 복원됩니다. 이전 저장은 기존 성장도를 인정해 보금자리 단계를 부여하고 빈 공간에 중심 보금자리를 배치합니다. 서버 저장·기기 간 동기화는 없습니다. 주민 오프라인 생산은 브라우저의 마지막 저장 시각으로 정산합니다.

`node verify.mjs`는 실제 Three.js와 대체 화면으로 완료 후 채집/취소/중복, 모든 보금자리 단계의 도달 가능성, 클릭 건설, 거래 수량·가격, 금화 배 구매, 낚시 단계·취소·희귀도, 꾸미기·친밀도·부탁 보상 중복, 해변·저녁 보상, 회전 좌표·카메라·조이스틱, 효과 정리와 저장 복원을 검사합니다. 브라우저 QA는 별도의 테스트 저장 키로 수행합니다.

GitHub Pages는 main의 루트에서 서비스합니다. `dist/index.html` 수정 시 루트 `index.html`과 `isletopia.html`도 동기화합니다. 후자는 자기 URL을 canonical/og:url로 사용하며 같은 저장 데이터를 공유합니다. 변경된 게임 규칙 모듈의 버전 쿼리도 함께 올립니다. Sites의 `.openai` 설정과 임시 QA 파일은 배포하지 않습니다.

공유 이미지 `dist/assets/isletopia-share-v1.jpg`는 홍보 일러스트입니다. Three.js는 MIT로 로컬 제공하며 선택적 Google Fonts 연결이 실패해도 시스템 글꼴을 사용합니다.

### 플레이어의 휴식

모닥불에서 쉬기를 선택하면 실제로 바닥에 앉아 불을 바라봅니다. 놓인 벤치에도 앉을 수 있습니다. 무릎을 앞으로 접고 몸을 부드럽게 낮추며 가벼운 숨쉬기 동작을 유지합니다. 카메라 회전·확대 중에는 앉아 있고 이동·작업·건설·항해 또는 일어나기 버튼으로 해제합니다. 휴식 자세는 일시적이며 저장한 진행 상태를 바꾸지 않습니다.

## 시안 기반 업데이트

관리 메뉴는 가벼운 2D SVG 아이콘과 이름만 표시하는 가로 슬라이드입니다. 바로 위에 붙는 반투명 트레이는 스와이프 또는 화살표로 이동하고 항목을 선택하면 기존 건설·업그레이드·이벤트 화면이 열립니다. 목록 위치는 생산 갱신 중에도 유지합니다. 주요 이벤트 대화는 중앙에 표시하고 다음·스킵 버튼을 확대했습니다.

자연 자원은 나무 6~10개, 돌 4~7개, 열매 3~5개의 보유량을 가지며 소진하면 사라집니다. 14~26초 후 건물·주민·다른 자원을 피한 새 위치에서 생성됩니다. 남은 수량과 재생성 대기는 저장됩니다. 채집·낚시는 완료할 때만 경험치 1을 얻고 최대 10레벨까지 성장합니다. 추가 획득 확률은 레벨당 2.5%씩, 최대 20%이며 나무·돌의 남은 총량을 초과하지 않습니다. 작업 속도는 유지합니다. 채집·생산 메뉴에서 숙련도를 확인합니다.

플레이어의 바닥·벤치 휴식과 일어나기, 멈췄다 걸으며 방향을 부드럽게 바꾸는 동물 배회를 추가했습니다. 캐릭터의 얼굴·볼·몸 비율, 잎과 가지, 부드러운 바위와 해변 장식, 색조·조명을 개선했습니다. 생성 시안과 동일한 사전 렌더 품질을 보장하는 것은 아니며 실제 기기 성능은 후속 플레이 테스트에서 다듬습니다.

## 평화로운 섬 업데이트

모바일 패널 축소, 처음부터 낚시, 지형 확장, 전투 제거, 주민·오프라인 생산과 저장 보호를 적용했습니다. 정확한 규칙과 검증 범위는 [IMPLEMENTATION.md](IMPLEMENTATION.md)에 기록했습니다.

## 자동 낚시 · v16

낚시 전용 카메라에서 앉기·던지기·찌 움직임·입질·당기기·자동 인양 동작을 이어갑니다. 결과는 잡았다!와 어획물·수량, 계속 잡기/그만하기로 표시합니다. 그만하기와 중간 취소 시 이전 카메라를 복원하고 미완료 보상은 지급하지 않습니다. 행동 문구는 채집중/잡는중으로 축약했습니다. 꾸미기 재료 버튼은 제목 옆에 배치하고 같은 목록의 아이템 아래에 재료를 펼칩니다.
