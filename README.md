# 아일토피아 · ISLETOPIA (islandstorygame)

모바일 플레이: https://guras1984.github.io/islandstorygame/

동물과 자연이 먼저 살아나고, 대화로 이웃을 맞이해 마을을 키우는 1인용 3D 웹 검증판입니다.

## 실행

`dist`를 정적 서버로 제공하세요. 예: `python3 -m http.server 8090 --directory dist`.

## 조작

- WASD/방향키: 이동 (한글 입력 상태 지원). 땅 클릭: 목적지로 걷기.
- 드래그: 카메라 회전. 휠: 확대/축소.
- 자원·사람·동물·게시판 클릭: 다가가서 채집·대화. 여러 행동이 있는 건물·나무는 대상 옆 작은 메뉴에서 선택합니다. 근처에서 E로도 상호작용.
- 모바일: 왼쪽 아래를 드래그하면 반투명 조이스틱으로 이동하며 손을 떼면 사라집니다. 짧은 터치는 이동·대상 선택, 오른쪽 드래그는 카메라 회전, 두 손가락은 확대·축소입니다.
- 건설: 분류 메뉴 → 위치 정하기 → 땅에서 미리보기 → 회전(R) → 확정. 취소(Esc)에는 재료를 사용하지 않습니다.
- 항해: WASD 이동, Space 함포 발사, 항해 메뉴에서 귀항·수리.

## 모아 반영한 기능

- 자연·동물 / 집·생활 / 채집·생산 / 주민 / 항구·탐험 / 게시판 / 환경·소리의 아이콘 메뉴. 다시 누르면 닫힙니다.
- 시설과 배는 3단계. 재료를 지불하면 외형·기능이 발전하고 다음 시설이 열립니다. 필요 시설의 단계와 비용을 카드에 표시합니다.
- 건물 배치·회전·무료 이동, 겹침/섬 밖 검사. 항구는 해안, 배는 항구에서 제작합니다. 시설 자리에 있는 자연 자원은 숨기고 옮기면 복원합니다.
- 주택 단계당 2명, 주택 단지 단계당 4명 수용. 추가 주택도 원하는 위치에 건설·업그레이드·이동할 수 있습니다.
- 빈방이 있으면 45초 간격으로 입주 희망자가 찾아옵니다. 이름·직업·정착 조건을 가진 방문자에게 허락해야 주민 수가 늘고, 거절하면 다음 방문자를 기다립니다. 새 집 완성 시에는 첫 방문자가 즉시 찾아옵니다.
- 주민에게 대화로 작업을 부탁하거나 메뉴에서 간편 배정. 특기와 일치하는 작업은 생산 +1. 일반 수집 3 + 시설 단계×2 + 창고 단계. 4초마다 생산하며 밭/과수원은 자체 식량, 식당은 식량을 금화로 바꿉니다.
- 자연 시설 단계가 오르면 토끼·새·사슴이 증가합니다. 연못에는 물고기·개구리, 심은 열매나무에는 30초 후 둥지와 새가 생깁니다.
- 중요한 첫 변화만 짧은 대화. 글 즉시 표시, 전체 스킵, 입주/작업 선택은 스킵해도 남습니다. 일상 말풍선은 간헐적으로 나오며 이동을 막지 않습니다.
- 실제 20분의 낮밤. 아침/낮/노을/밤의 하늘과 조명, 달·별·창문·가로등 변화.
- 맑음 210초 / 비 90초 주기. 주민·방문자는 우산을 쓰고 동물은 쉬어갑니다. 비가 그치면 낮에는 무지개, 숲에는 E로 채집하는 버섯이 나타납니다.
- 음악은 사용자의 소리 켜기 동작 후 시작합니다. Web Audio로 합성한 자체 선율·화음과 자연 소리이며 시간대/날씨에 따라 전환됩니다. 음량·뮤트 설정을 저장하며 숨겨진 탭에서는 음량을 줄입니다.
- 선택 참여형 게시판 이벤트 4개. 수락 이후 직접 수집한 재료/주민/비 온 뒤 버섯 목표를 달성하면 금화·재료·장식을 한 번만 지급합니다. 장식은 게시판 옆에 표시합니다.
- 마을 회관 2단계 이후 중반의 항해 해금. 주변 섬 3곳 발견/정착, 바다 괴물 전투, 함선 강화. 기존에 배를 만든 저장 데이터는 계속 항해할 수 있습니다.

## 저장과 검증

현재 브라우저 localStorage 자동 저장입니다. 건물 단계·배치·입주 주민·작업·방문자·시간·날씨·이벤트·장식·음량을 복원합니다. 예전 검증판의 주민과 작업은 새 구조로 옮겨 유지합니다. 오프라인 생산은 없습니다.

`node verify.mjs`로 실제 Three.js와 화면 대체 환경에서 입력·이동·애니메이션·배치/회전/업그레이드·입주 허락·생산·대화 스킵·이벤트 중복 보상 방지·날씨·음악 스케줄·전투·저장 이전을 검사합니다. 브라우저에서는 별도 테스트 저장을 사용해 대화/입주/업그레이드/회전 확정/음악 메뉴를 확인했습니다.

계정·서버 저장, 친구 추가·방문은 사용자 요청으로 보류했습니다. Roblox 이전 시 규칙과 저장 구조를 참고하되 씬과 동작은 Roblox Studio/Luau로 다시 구현해야 합니다.

Three.js 0.170.0은 로컬 vendor로 포함(MIT). Google Fonts는 선택적 온라인 폰트이며 연결이 없으면 시스템 글꼴로 표시합니다.

## 주인공·메뉴·줌 업데이트

- 주인공 `준이` 1종: 참고 그림의 왕관·날개·둥근 네모 형태와 노란 X를 3D 모델로 구현했습니다. 주인공과 주민 모델은 분리되어 있습니다.
- 처음 시작할 때 주인공 선택 → 옷/왕관 색 꾸미기 → 시작합니다. 옷은 바다 파랑/숲 초록, 왕관은 햇살 노랑/노을 주황입니다. 미리보기는 실제 게임과 같은 3D 모델입니다.
- 기존 섬 저장도 처음 한 번 꾸미기를 거치며 자원·건물·주민은 유지됩니다. 선택 후 외형은 저장되고, 환경·소리 메뉴의 꾸미기에서 다시 바꿀 수 있습니다. 추가 주인공/색상은 `character.js`의 목록과 모델 생성기를 확장하는 구조입니다.
- 관리 메뉴는 이름·단계·재료 아이콘·주요 행동만 표시합니다. 긴 설명·효과·이동 기능은 자세히 보기 창에 분리했고, 잠긴 건물은 접힌 목록에 있습니다. 배치가 시작되면 관리 메뉴가 접힙니다.
- 휠과 두 손가락 핀치로 캐릭터 중심 줌(4.5~80)을 조절합니다. 두 손가락을 벌리면 가까워지고 모으면 멀어집니다. 핀치 중 이동·회전·배치 변경을 막고 마지막 손가락이 떨어질 때까지 잘못된 탭을 무시합니다.
